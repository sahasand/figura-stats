Coverage ("targets met") means every quantity the case declares in exact_targets was actually credited by a performed comparison — a coverage failure marks a case TARGETS UNMET even if every comparison that did run passed. Display artifact means both paths computed the same number and only the rendered string differs, within half a display step. Defect means the values themselves disagree beyond a relative tolerance of 1e-6. Missing quantity means something expected was never compared at all — a coverage failure, not a value disagreement. Script divergence means the exported .R does not reproduce what the screen showed. Count mismatch means the two paths analysed different rows.
