Compared names the two artifacts behind the Figura and Python columns, in that order, because "Figura" is three different things depending on the tier. screen vs Python checks the numbers the user was actually shown against the independent implementation. exported script vs Python checks the harvest from re-running the .R the app exports — so a defect on that line indicts the export path, and says nothing against the displayed numbers unless a screen vs Python row fails too. screen vs exported script is Path A against itself: there the Python column holds the exported script's own value, not Path B's.

Coverage ("targets met") means every quantity the case declares in exact_targets was actually credited by a performed comparison — a coverage failure marks a case TARGETS UNMET even if every comparison that did run passed. NOT COMPARED marks a case that is registered and ran, but whose two paths were never set against each other; it carries no guarantee at all, and it is counted in the cases tile's denominator so the tile can never read complete while such a case exists. Display artifact means both paths computed the same number and only the rendered string differs, within half a display step. Defect means the values themselves disagree beyond a relative tolerance of 1e-6. Missing quantity means something expected was never compared at all — a coverage failure, not a value disagreement. Script divergence means the exported .R does not reproduce what the screen showed. Count mismatch means the two paths analysed different rows. Decision mismatch means the two paths chose different summary statistics for a Table 1 variable — mean ± SD where the other chose median (IQR), say — which is a defect even when every number in the row is individually correct.
